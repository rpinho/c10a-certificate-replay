# Real Grothendieck constant: certificate replays (C10a)

Moved to [rpinho/math-certificates/c10a](https://github.com/rpinho/math-certificates/tree/main/c10a).

Recorded bounds: **1.773 ≤ C₁₀ₐ ≤ 1.77987164**, due to Heilman–Jones–Malavolta and Bo Peng (using Junyu Ren's construction), respectively. These are replay receipts, with no new bound or review of the proofs. See [Tao PR #300](https://github.com/teorth/optimizationproblems/pull/300).
